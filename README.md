# Spring Security JWT Authentication

A Spring Boot project implementing secure REST APIs using JWT authentication, Spring Security, and MySQL.

### Features
- JWT token generation and validation
- BCrypt password encryption
- Role-based authorization (USER and ADMIN)
- Stateless authentication
- MySQL database integration

### Tech Stack
Java | Spring Boot | Spring Security | JWT | Spring Data JPA | MySQL | Maven | Postman

### Testing
APIs tested using Postman for login, profile access, and role-based authorization.
